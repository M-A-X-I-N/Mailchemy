# Planning

This directory contains **explicitly authorized active implementation roadmaps and task plans**.

It is intentionally separate from:

- `docs/` — durable Mailchemy architecture, terminology, and design authority;
- `research/` — evidence about native systems and cross-system semantic investigations;
- `.agents/` — agent-specific workflow/procedure.

A plan may propose provisional implementation choices, sequencing, experiments, and acceptance criteria. It does **not** override `docs/ARCHITECTURE.md` or `docs/GLOSSARY.md`. If implementation work proves or changes a durable architectural fact, promote that conclusion into `docs/`.
